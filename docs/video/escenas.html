SQL: solo lectura

Se quitan los comentarios -- /* */
Se rechaza el punto y coma ;
Solo SELECT WITH VALUES
Bloquea SELECT INTO y CALL
Sin límite → FETCH FIRST 1000 ROWS ONLY
SELECT * FROM CLIENTES; DROP TABLE CLIENTES
Rechazada · sentencias encadenadas
DELETE FROM CLIENTES
Rechazada · no es una lectura
SELECT NOMBRE INTO :X FROM CLIENTES
Rechazada · SELECT INTO
